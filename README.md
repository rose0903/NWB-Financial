# NWB Financial

NWB Financial is a fictional multi-currency banking application.

## Included
- Customer registration and login
- Customer dashboard
- USD, GBP, EUR, NGN, ZAR, CAD and AUD wallets
- Internal transfers
- Currency exchange
- Withdrawal requests
- Transaction history
- Administrator dashboard
- Customer ledger crediting
- SQLite database

## Local setup
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
